# AMR Sensor Navigation Simulation

This Python script simulates the core mechanics of an Autonomous Mobile Robot (AMR). It demonstrates how sensors (LIDAR and camera) are used to perceive the environment and how basic navigation logic, including obstacle avoidance and battery management, is implemented.

## Language

`python`

## How to Run

Save the code as `amr_simulation.py` and run it from your terminal using: `python amr_simulation.py`
